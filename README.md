## 先拆概念：大带宽 ≠ 大流量

这两个词经常被混着用，但它们是完全不同的东西。

**端口带宽**决定你最快能跑多快。DMIT 洛杉矶在售套餐的端口从 1Gbps 到 10Gbps。10Gbps 是个上限，不是承诺——单线程跑不出 10Gbps 是常态，多线程并发才吃得住。

**月流量额度**决定你一个月能动多少数据，单位是 TB。这里的坑最容易被忽略：DMIT 的流量是**双向计费**，上传和下载都会计入。跑 P2P、做镜像同步、备份大量文件时，双向计费会让流量消耗比你以为的快一倍。

**超量策略**决定跑完之后你是被停机、被断网，还是被限速。DMIT 的规则是"限速不限量"：高速流量用完后降到指定速度继续跑，不停机。不同套餐的降速档位差别很大，最低 4Mbps，最高 500Mbps。

只盯着"10Gbps"三个字下单的人，最后往往是发现自己每月只有 1TB 双向流量，三天就跑完了。

## 超量之后会发生什么，以及三个容易踩的点

**限速不限量是真的，但档位差别很大。** T1 系列超量后还能跑 100–500Mbps，基本不影响日常使用；Pro 和 EB 的入门档超量后降到 4Mbps，这个速度只够收邮件和 SSH。如果你的用量本来就接近额度，选套餐时要按"降速档位"而不是"原价"来判断值不值。

**流量双向计费。** 上传下载都算。做种子、做备份、做镜像的，实际可用流量大概是标注数字的一半。

**换 IP 有前置条件。** 多家测评站整理的规则是：实例开通满 7 天、距上次换 IP 至少 15 天、ICMP 和 TCP 全端口不可达、剩余服务期不少于 7 天，满足条件才免费换。IP 被封不是随时能换的，这点对做中转的人很关键。

退款政策方面，第三方测评提到的是 3 天内可申请全额退款（已用流量不超过 30GB），30 天内可按剩余时长或流量部分退款。这类政策会调整，下单前值得自己确认一遍。

## 几个高频问题

**流量跑满了会停机吗？** 不会。高速流量用尽后按套餐档位降速，继续不限量使用，这是 DMIT 从 2024 年底起就在执行的规则。

**能解锁流媒体吗？** 有第三方实测报告显示，部分洛杉矶 IP 段可以原生解锁 Netflix、Disney+、ChatGPT 等，IP 风险评分偏低。但 IP 段会被轮换，解锁状态随时变化，任何商家都不会为此做承诺——需要稳定解锁的场景，别把这一点当作选购依据。

**月付还是年付？** 年付单价更低（T1 WEE 年付 $36.90，折合每月约 $3.08），但库存和价格都在动，第一次用建议月付跑一个月，确认线路和性能符合预期再转年付。

**AS3 和 AN5 差在哪？** 只差硬件平台：AS3 是 AMD EPYC 7003，AN5 是 EPYC 9005，同配置下路由和流量规则一致，AN5 单核性能更强、价格更高。纯建站和下载场景，AS3 的性价比更高；CPU 密集型业务才值得为 AN5 多付那两成。

平台和套餐随时可能调整，最终以下单页的库存、价格和配置为准。挑之前建议先用官方提供的测试 IP 和 Looking Glass 自己 ping 一轮，比看任何测评都直接。
